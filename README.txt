DIGITAL LITERACY HUB — UPDATED COMPETITION BUILD

A self-guided educational platform for practical digital literacy, designed around:
PEOPLE • PLANET • PROSPERITY

WHAT IS NEW
- Dedicated Digital Literacy Hub logo using the navy, teal and gold identity
- Mobile slide-out side navigation with backdrop, close button and keyboard support
- Judge-friendly homepage explaining the purpose and learning journey without requiring a presenter
- Interactive Learning hub linking the Safety, Information, AI and Planet activities
- Digital Literacy Assessment with category-level scoring and instant explanations
- My Progress page that stores the latest assessment result locally in the browser
- Searchable Digital Literacy Glossary
- Expanded About page explaining the problem, aim and Learn → Practise → Test → Improve → Apply approach
- Clear People, Planet and Prosperity explanation on the homepage
- Responsive layouts for desktop, tablet and mobile
- Accessibility improvements for mobile navigation and interactive controls
- St Columba's High School logo remains in the footer as school identification; the national coat of arms is not used as the Hub logo

MAIN AREAS
- Home — project purpose, People/Planet/Prosperity, learning journey and assessment entry point
- Learn — ten digital skill areas with learning guidance and progress-style visual bars
- Interactive — practical activities and labs
- Assessment — 12-question interactive digital literacy assessment with feedback and category scoring
- My Progress — locally stored latest assessment profile and recommended focus areas
- Digital Future — careers, entrepreneurship and digital opportunity
- About — project problem, aim, audience and methodology
- Glossary — searchable learner-friendly terminology
- People — communication, citizenship, inclusion, identity and wellbeing
- Planet — sustainability, e-waste and responsible technology use
- Prosperity — careers, entrepreneurship and digital opportunities
- Safety Lab — phishing, passwords, digital footprint and scam awareness
- Information Lab — fact-checking and source evaluation
- AI Lab — AI basics, limitations and responsible use
- Zimbabwe — local digital context
- Resources — continued learning resources
- Pledge — responsible digital habits

DESIGN
Primary identity:
- Deep Navy #123B5D
- Teal #2A9D8F
- Gold #E9B949
- White / light neutral backgrounds

LOGO CONCEPT
The logo combines an open book with a digital network. The network represents connectivity and the digital world; the book represents learning; three accent nodes subtly connect to People, Planet and Prosperity.

TECHNOLOGIES
- HTML5
- CSS3
- Vanilla JavaScript
- No framework required
- No server required for normal use
- Assessment results are stored only in the browser's localStorage

RUN
Option 1:
Open index.html in a modern browser.

Option 2:
From the project folder:
python -m http.server 8000

Then visit:
http://localhost:8000

NOTES
- The password activity is for fictional examples only. Never enter a real password.
- Interactive activities run locally in the browser.
- There are no accounts or registration requirements.
- The project does not send assessment results to a server.
